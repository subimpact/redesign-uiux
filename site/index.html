Two layers, one bridge

The judgment layer comes from taste-skill. It reads the brief, declares a Design Read, then sets three dials: DESIGN_VARIANCE, MOTION_INTENSITY and VISUAL_DENSITY. An anti-slop rule set keeps the LLM defaults out, and a pre-flight checklist checks the result before anything ships.

The catalog engine comes from ui-ux-pro-max. A local BM25 search ranks real catalogs: styles, palettes, font pairings, GSAP motion presets, UX guidelines and 22 stack guides, so every recommendation is grounded in data, not vibes. The dial bridge attaches the dials to the query, and both layers act on the same page.
